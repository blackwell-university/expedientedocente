¿Cómo se edita?
Escribe el HTML del correo. Lo que va entre llaves lo reemplaza el sistema con los datos reales:
• {{variable}} inserta un texto (por ejemplo {{docente}}).  • {{{variable}}} inserta un bloque HTML que arma el sistema (tablas, listas).
• {{#condicion}}…{{/condicion}} muestra el contenido solo si se cumple; {{^condicion}}…{{/condicion}} solo si no se cumple.
• Toca una variable de la lista para insertarla donde está el cursor. Las marcadas con * son obligatorias (el correo no debe salir sin ellas).
• La vista previa usa datos de ejemplo. Antes de guardar puedes enviarte un correo de prueba. Si algo sale mal, “Restaurar original” devuelve el diseño de fábrica.
